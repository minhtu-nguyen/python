
# Day 1 — Expense Tracker CLI

A command-line expense tracking application written in Python.

## Features

- Add expenses
- Store expenses in JSON
- List transactions
- Summarize by category
- Filter by month
- Export to CSV

## Requirements

Python 3.11+

## Development

Run the application:

    python main.py --help

Run tests:

    python -m unittest discover -s tests -v
